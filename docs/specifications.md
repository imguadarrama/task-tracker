Section B — Technical Full‑Stack Review (60%)
Build a minimal task‑tracking application consisting of a backend API and a simple frontend interface. You may use any modern stack you are comfortable with (e.g., React + Node/Express, Next.js, Django, FastAPI, etc.). Focus on correctness, clarity, and maintainable code rather than UI polish.
Backend Requirements
• Implement user registration and login.
• Passwords must be securely hashed using a standard algorithm.
• Create an authenticated API for managing tasks.
• Each task should include: title, description, status (todo, doing, done), and owner.
• Implement endpoints for creating, listing, updating, and deleting tasks.
• Users must only be able to modify their own tasks.
• Support filtering tasks by status and searching by keyword.
• Return appropriate HTTP status codes and structured error messages.
Frontend Requirements
• Create login and registration forms.
• Display a list of tasks belonging to the authenticated user.
• Allow users to create, edit, and delete tasks.
• Support filtering tasks by status and keyword search.
• Display loading states and error messages.
Code Quality Requirements
• Include at least one automated test (backend or frontend).
• Provide a short README explaining how to run the project.
• Document any design decisions or tradeoffs made during implementation.
• List at least three possible improvements you would implement with more time.
